想用 ChatGPT、Claude 这些大模型的 API，但官方价格不便宜、海外支付又麻烦——于是你找到了"中转站"。充个几块钱就能跑起来，价格只有官方的几分之一，心里又有点没底：**这么便宜，靠谱吗？"倍率"又是什么东西？**

这篇文章从最底层的 Token 计费讲起，一步步拆解中转站为什么能卖得便宜、倍率到底在算什么、以及你该怎么选才不踩坑。

### Token：大模型计费的最小单位

大模型不按"字数"收费，而是按 **Token** 收费。Token 是模型内部处理文本的最小计量单位——它既不等于一个汉字，也不一定等于一个英文单词，而是分词器（tokenizer）把文本拆分后得到的片段。

一些直观参考：

- 英文 1 个常见单词 ≈ 1 Token
- 中文 1-2 个汉字 ≈ 1 Token
- 标点、空格、换行也会占用 Token
- 代码、JSON、URL 往往消耗比你预想更多的 Token

这就是为什么模型价格表写的是"每百万 Token 多少钱"，而不是"每千字多少钱"。

### 官方是怎么收费的？

所有大模型厂商的计费结构都遵循同一套框架：**输入 Token + 输出 Token 分开计费，输出通常比输入贵 3-5 倍**。

基本公式：

> **费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价**

以 Claude Sonnet 4.6 为例（官方 API 价格）：

| 项目 | 单价（每百万 Token） |
|------|---------------------|
| 输入 | $3 |
| 输出 | $15 |
| 缓存命中输入 | $0.30 |

你发一条 1000 Token 的提示词，模型回复 2000 Token，费用就是：

```
1000 / 1M × $3 + 2000 / 1M × $15 = $0.003 + $0.03 = $0.033
```

看着不多？但在高频调用场景下（比如 AI 编程助手每天几百次请求），月账单轻松过百美元。

![Token与文字的对应关系示意图](/img/2026-05-15/token-vs-text-comparison.jpg)

### 缓存和 Thinking 模式让账单更复杂

两个机制会显著改变你的实际花费：

**Prompt 缓存**：如果你每次请求都带着一大段相同的系统提示词，厂商不会每次都按原价算。命中缓存的部分，输入价格可以低到原价的 1/10。这就是为什么有些中转站宣传"缓存命中直接白送"——本质上是厂商的折扣。

**Thinking / Reasoning 模式**：Claude 的 Extended Thinking、GPT 的 o3 系列，在输出最终答案前会先"深度思考"，生成额外的思考 Token。这些 Token 也要计费，所以 thinking 模式比普通模式贵是正常的。

### 中转站到底是什么？

中转站本质上是**位于你和模型厂商之间的聚合转发服务**。它做三件事：

1. **统一接入**：把 OpenAI、Anthropic、Google 等不同厂商的 API 包装成统一格式（通常是 OpenAI 兼容格式），你换个 Base URL 和 Key 就能用
2. **解决支付和网络**：帮你搞定海外信用卡和科学上网问题
3. **额度管理**：提供充值余额、Key 管理、用量统计等运营功能

从技术架构看，绝大多数中转站底层跑的是开源项目 **One API** 或它的衍生版（New API 等），Docker 一键部署，门槛很低。

### 中转站为什么能卖这么便宜？

这是最核心的问题。价格低的原因按渠道类型完全不同：

| 渠道类型 | 成本来源 | 典型倍率 | 稳定性 |
|----------|----------|----------|--------|
| 官方直连（官转） | 正规 API Key，批量采购可能有折扣 | 0.8 - 1.5 | 高，等同官方 |
| 云厂商渠道 | AWS Bedrock / Azure OpenAI 等 | 0.7 - 1.2 | 较高 |
| 逆向渠道 | 破解网页版协议，号池轮换 | 0.05 - 0.3 | 低，随时可能翻车 |
| 2API 渠道 | 把 Plus/Pro 订阅逆向为 API | 极低 | 不稳定，受封号影响 |

**便宜的根本原因：逆向渠道的成本接近于零。**

逆向是怎么运作的？简单说就是：批量注册免费账号 → 逆向网页通信协议 → 搭建中间服务器 → 号池轮换调用。每个账号有免费额度，上万个账号组成号池，成本被摊到极低。

但这不是没代价的。正如一位知乎用户的总结："中转站有个悖论——它越便宜的时候号越贱，个人组号池几乎没成本；它贵的时候要么自己找号源，要么自己拼车，但对个人信息收集能力有一定要求。"

逆向渠道面临的核心风险：

- **官方风控升级**：OpenAI、Anthropic 会不断杀号，账号池随时可能被一锅端
- **智商波动**：算力不足时普号优先被降级，回复质量不稳定
- **偷梁换柱**：你付的 Opus 的钱，后台可能偷偷路由到 Sonnet 甚至 Haiku

### 倍率到底是什么？

倍率是中转站**把官方美元成本折算成平台内部余额的换算系数**。

![AI API中转站倍率计算机制](/img/2026-05-15/multiplier-mechanism.jpg)

官方世界用美元计价，中转站世界用人民币余额计价。两套体系之间需要一个桥梁，这个桥梁就是倍率。

**计算公式：**

> **实际扣费 = 消耗 Token 数 × 官方单价 × 倍率**

大多数中转站默认 1 元人民币 = 1 美元额度，所以：

- **倍率 1**：跟官方同价
- **倍率 0.8**：打了八折
- **倍率 0.5**：半价
- **倍率 0.1**：一折（几乎可以断定是逆向渠道）
- **倍率 2**：比官方还贵（含运维利润或代理加价）

实际上倍率还可以进一步拆分。中转站面板里你可能会看到：

- **模型倍率**：不同模型的基础系数（Opus 比 Sonnet 贵）
- **补全倍率**：输出 Token 相对输入 Token 的价格比
- **分组倍率**：不同用户组的额外折扣或加价

最终扣费是这些倍率的乘积。所以看倍率不能只看一个数字，要看**综合成本**。

### 怎么判断一个中转站靠不靠谱？

根据三篇参考文章中的经验，总结几条实操建议：

**先小额测试**。不管哪家，先充 5-10 块试水。测响应速度、模型效果、是否真的是宣传的模型。

**倍率太低要警惕**。Opus 官方价格本身就很贵，如果某家倍率低到 0.1，基本可以断定是逆向渠道，甚至可能偷梁换柱。正常官转倍率在 0.7-1.5 之间。

**不要把鸡蛋放一个篮子**。注册 2-3 家互为备份。逆向翻车是常态，中转站跑路也时有发生。

**验证模型真假**。用同一个复杂编程题或数学题，分别问官方和中转站，对比回答质量。不要只靠"你是什么模型"这种问题——中转站可以通过注入提示词伪造回答。

**注意隐私**。你发给 API 的所有内容，中转站理论上都能看到。不要通过中转站发送密码、商业机密。

### 常见问题

**Q: 中转站便宜就一定是逆向吗？**

不一定。有些官转中转站通过批量采购、利用缓存机制、薄利多销等方式也能做到比个人直接购买便宜。但如果倍率低于 0.3，大概率涉及逆向渠道。

**Q: 倍率 1 的中转站是不是就等于直接用官方？**

效果上基本等同（如果是官转渠道的话），但你额外获得了国内直连、人民币支付、统一管理等便利。中转站的运营成本通常通过略高于 1 的倍率来覆盖。

**Q: 用中转站会不会被官方封号？**

官方封的是中转站的 Key，不是你的。但如果中转站被封，你充的钱可能拿不回来。所以选择运营时间长、口碑好的平台更重要。

**Q: 缓存命中和倍率是什么关系？**

缓存命中降低的是官方侧的输入成本，倍率是中转站在此基础上的二次折算。两者是乘法关系：最终扣费 = 官方成本（含缓存折扣）× 倍率。

### 小结

中转站便宜的核心原因是渠道差异——官转靠批量采购和薄利多销，逆向靠几乎为零的号池成本。倍率则是中转站把官方美元成本折算成平台余额的换算系数，不同倍率对应不同的渠道质量和风险水平。

理解了这两点，你就能在"便宜"和"靠谱"之间做出明智的选择。
